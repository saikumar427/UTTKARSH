# Uttkarsh English High School & Little World Kindergarten — Official Website

Official, high-performance, mobile-responsive static website for **Uttkarsh English High School & Little World Kindergarten** (*"Education For All"*, Est. 2006, Govt. Recognised, Gate No. 7, Malwani, Malad West, Mumbai – 400095).

## Quick Preview

- **Direct Local Open**: Double-click `index.html` in any modern browser.
- **Local Web Server**:
  ```bash
  python -m http.server 8080
  ```
  Then open `http://localhost:8080`.

## Updating Content, Photos, or Partner Links

All school details, testimonials, activity galleries, Google Photos album links, facility videos, and supporter/partner external links (e.g., `byntix.com`, `tatapower.com`, `feedingindia.org`) are centralized in `js/data.js`.

## Deploying to GitHub Pages

1. Commit and push all files in this directory (including `.nojekyll` and `assets/`) to a GitHub repository.
2. Open **Settings → Pages** in your GitHub repository.
3. Under **Build and deployment**, choose **Deploy from a branch** → select `main` and `/ (root)` → click **Save**.
